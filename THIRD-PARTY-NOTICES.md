# Сторонние компоненты

Граф NuGet проверен 27 августа 2026 года по восстановленным метаданным прямых и
транзитивных пакетов. Коммерческих и proprietary-лицензий не найдено.

| Лицензия | Компоненты |
| --- | --- |
| MIT | Microsoft `.NET` packages, Mediator, Humanizer, Swashbuckle |
| Apache-2.0 | FluentValidation, Castle.Core, xUnit |
| BSD-3-Clause | NSubstitute |
| PostgreSQL | Npgsql и PostgreSQL server image |

Точные NuGet-версии и хеши находятся в `packages.lock.json`. Этот файл описывает
только сторонние компоненты и не назначает лицензию исходному коду репозитория.
